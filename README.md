# Los 2 Hermanos - Sistema Integral de Gestión

Sistema desarrollado para la gestión de ventas y repartos de gas, leña, carbón y alimentos.

## Arquitectura

- **backend/**: FastAPI (Python) - API Principal
- **web/**: Next.js (TypeScript) - Panel de Administración
- **mobile/**: React Native + Expo (TypeScript) - App para Choferes
- **supabase/**: PostgreSQL - Base de Datos
